# Sistema de Gestão de Infrações Escolares

## Sobre o Projeto

O Sistema de Gestão de Infrações Escolares tem como objetivo digitalizar e organizar o processo de registro, análise e conclusão de infrações disciplinares cometidas por alunos.

O sistema garante:

- Transparência
- Rastreabilidade
- Comunicação eficiente
- Segurança das informações
- Conformidade com a organização didática

---

##  Objetivo

Desenvolver um sistema capaz de:

- Registrar infrações
- Aplicar penalidades
- Notificar responsáveis
- Permitir assinaturas digitais
- Manter histórico completo das ocorrências

---

##  Arquitetura

O sistema foi modelado utilizando:

- Arquitetura em Camadas (3-Tier)
- Padrão MVC
- Modelagem UML
